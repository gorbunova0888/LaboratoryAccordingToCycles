
# Лабораторная работа: Циклы с пред- и постусловием

## Автор
Горбунова Настя (Вариант 3)

## Цель
Вычислить таблицу значений мощности тока P от сопротивления R
на двух участках с разными шагами, используя цикл do-while
для первого участка и цикл while для второго.

## Формула
P = R · (ε / (R + r))²

где:
- ε = 115 В (ЭДС)
- r = 29.7 Ом (внутреннее сопротивление)

## Входные данные
Аргументы R: 10, 20, 30, 40, 50, 100, 150, 200, 250, 300 Ом

## Выходные данные
Таблица значений R и P

## Как запустить
Открыть проект `CyclesLab/CyclesLab.slnx` в Visual Studio
и запустить без отладки: Ctrl+F5.
